# Repurly Channel-Safe Revision

This package updates Repurly so it avoids overpromising platform integrations.

## Main change

Public/customer-facing wording now uses **campaign/output channels** instead of **connected channels** unless the screen is specifically discussing verified API account connections.

## Why

The product can support multi-channel campaign production immediately through exports, briefs, scripts, captions, and manual-posting workflows. Direct publishing should only be marketed where each provider integration has been approved and tested.

## Plan language

- Starter: 2 campaign/output channels
- Operator: 6 campaign/output channels
- Studio: 30 campaign/output channels

## Launch-safe output examples

- LinkedIn post
- LinkedIn carousel outline
- Facebook Page post
- Instagram caption
- Google Business Profile update
- Email/newsletter
- Blog post
- YouTube title/description/script
- TikTok/Reels hook/caption/shot list
- Threads post
- X post/thread export
- WhatsApp/referral message

## Integration status

LinkedIn remains the primary launch workflow. Other channels should be treated as export/supporting outputs until direct integrations are configured, approved, and end-to-end tested.
